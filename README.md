# DJDX

A score viewer for beatmania IIDX, SOUND VOLTEX, DDR, and Polaris Chord.

| Folder | Project |
|---|---|
| [`Apple/`](Apple) | DJDX for iOS, iPadOS and watchOS |
| [`Android/`](Android) | DJDXGo, DJDX for Android |
| [`Studio/`](Studio) | DJDX PEAK Studio, the macOS tool for training the result detection models |
